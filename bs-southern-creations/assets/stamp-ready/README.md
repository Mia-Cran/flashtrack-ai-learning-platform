# Stamp-ready logo files (from your photo)

Upload these when ordering a custom heated stamp, foil stamp, or rubber stamp.

## Best files to upload

### For heated stamps / branding irons / rubber stamps (ONE color)
- `BSC-logo-stamp-black.png` — full logo, black on white (most shops want this)
- `BSC-logo-stamp-black-transparent.png` — full logo, black on clear
- `BSC-mark-stamp-black.png` — flower only (better for small 1-inch stamps)

### For printed tags / stickers / foil artwork reference
- `BSC-logo-color-transparent.png` — full color logo
- `BSC-logo-color-white-bg.png` — full color on white
- `BSC-mark-color-transparent.png` — flower only in color

## Suggested stamp size
- Hang tags / gift boxes: 1.5–2 inches
- Small packaging: use the mark-only file at ~1 inch

## Tip
Tell the seller: "single-color stamp of this logo" and attach the black PNG.
