# B's Southern Creations — website

Standalone marketing site for **B's Southern Creations**.

## Preview locally

```bash
cd bs-southern-creations
python3 -m http.server 5174
```

Open http://localhost:5174

## What’s included

- Clean SVG logo recreation (the phone photo of the screen had moiré — swap in your final export anytime)
- Landing page: hero, creations, custom orders, contact form
- Mobile-friendly layout

## Swap the logo

Replace `assets/logo.svg` with your final Vistaprint/logo-maker PNG or SVG, then update the `<img>` paths in `index.html` if the filename changes.
